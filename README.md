# Nashville Numbers

An iOS app for musicians to learn and play the Nashville Number System.

## What It Does

Nashville Numbers helps musicians:
- Read and interpret Nashville Number System charts
- Transpose charts instantly to any key
- Practice chord progressions by ear using numbers instead of note names
- Build fluency in the universal language of session and worship music

## Why Nashville Numbers

The Nashville Number System is the shorthand that makes musicians adaptable — call any key on the fly, follow a chart you've never seen, transpose mid-song. This app makes that skill learnable and practical for players at every level.

## Tech Stack

- Swift / SwiftUI
- iOS 17+
- Xcode 15+

## Getting Started

1. Clone the repo
2. Open `Nashville.xcodeproj` in Xcode
3. Build and run on simulator or device
